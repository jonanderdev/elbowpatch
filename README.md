## Why another writing app?

There are good open editors already. Elbowpatch is for one combination:

- **A page you want to open every day.** One column, good type, nothing else on screen.
- **A history you can walk back through.** Every moment is kept automatically; look back, bring a version back, nothing is ever deleted. No commits, no save button.
- **Your files.** Plain Markdown, exportable in one click, synced only to a place you connect.
- **Any device.** An installable web app that works offline, on phones too. Free, and self-hostable.
